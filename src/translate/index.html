Fog Translate

Translates the Dead by Daylight chat while you play. It reads any script, including Cyrillic, Korean, Japanese and Chinese, and shows the translation in a small click-through window on top of the game.

    What it does

    Any script
    Cyrillic, Korean, Japanese, Chinese, Latin with accents: the AI model reads the chat, spots the language and translates it.
    13 target languages
    English, German, French, Spanish, Italian, Portuguese, Polish, Russian, Turkish, Dutch, Chinese, Japanese and Korean.
    Only new lines
    Sends only the strip with the new lines and nothing while the chat is closed. When the chat moves fast, it collects the lines and sends them together, so none is lost.
    Right above the chat
    Shown only while the chat is visible. Pick another spot, hide it with Ctrl+Alt+T, or keep it out of screenshots and recordings.
    Costs under control
    A daily limit, 300 requests by default, a test with a made-up chat and the time each answer took. Nothing is sent before you confirm what goes to the service.
    Easy to set up
    A setup assistant for service and key, updates checked against a SHA-256, no administrator rights. The window in six languages, light or dark.

    How it works

    1. Mark the chat area once. Drag a box around the chat. The area is stored relative to the game window, so it survives a different window size.
    2. Press Start. The program looks at that area twice a second and only reacts when the text has changed.
    3. Read the translation. Language, name, translation and the original in small print appear in the overlay and fade after 25 seconds.

    Pick a service

    The picture sent to a service can show other players' names and messages. API keys are stored encrypted with Windows DPAPI.
