Two free Windows tools for Dead by Daylight. Fog Scout shows the callout map when the match starts. Fog Translate translates the chat while you play.

Download What they do

Unofficial fan tools. They read screen pixels, nothing else.

Fog Scout

Shows the callout map of the map you are on, right when the match starts. After the round the map goes away again.

  • Automatic callout mapsReads the map name from the screen. 56 maps, six map styles.
  • Match statisticsKills, escapes, bloodpoints and waiting times per round, kept on your PC.
  • Recording with OBSRecords each match and cuts the highlights in the clip editor.
All Fog Scout features

Fog Translate

Translates the Dead by Daylight chat while you play, from any script.

  • Any scriptCyrillic, Korean, Japanese, Chinese, Latin with accents.
  • 13 target languagesThe translation appears in a small window right above the chat.
  • Pick a serviceClaude, the free tier of Gemini, or Ollama on your own PC.
All Fog Translate features

Built to stay out of the game

Both tools were designed around one rule: do not interact with Dead by Daylight.

Fair play in detail

Reads the screen

Screen pixels, the way OBS or Discord screen sharing does, and window information.

Never touches the game

No input to the game, no memory reading, no injection, no game files changed.

At your own risk

They are still unofficial. Behaviour Interactive has not approved map overlays or region tools.
