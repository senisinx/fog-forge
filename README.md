# Fog Forge

Source of [fogforge.app](https://fogforge.app): the landing page for [Fog Scout](https://github.com/senisinx/fog-scout) and [Fog Translate](https://github.com/senisinx/fog-translate).

A single static page (`index.html`) served by GitHub Pages. Screenshots are in `img/`.

The Fog Scout app screenshots (`overview`, `maps`, `overlay*`, `stat*`, `recordings`, `calculator`, `server`, `settings`, `setup`) are rendered with `tools/screenshots.py` from the fog-scout repository: English, 1560×1176, zoom 1.15, 300 synthetic rounds, converted to WebP. `recordings` uses demo recordings on a substituted drive (no real paths or screenshots).
